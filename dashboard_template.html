The Conditioning Atlas

Priming windows, doses, and persistence of induced environmental memory in marine invertebrates — experiments from papers.

Priming likelihood → GitHub repository
The framework says the application program is to identify the windows, identify the doses, and characterize how long the induced memory persists relative to production timescales. This is that table, made filterable. Persistence is days from the end of conditioning to the assessment; a 0 means offspring were spawned straight into the challenge, which is why so much of this literature cannot speak to memory duration at all. “not reported” is never inferred or filled in. One caveat: a handful of rows were conditioned continuously, so their persistence value is a tracking window rather than a post-conditioning recovery gap — those rows say so in Notes, and should not be ranked against clean-gap rows.

Where the evidence is — and is not

Experiments per taxon × stressor. Empty cells are the map of what nobody has run. Hover a cell for the studies in it.

Which window was primed

The life stage the conditioning exposure was applied to. The framework names embryo–larval development as the programming window; the literature overwhelmingly conditions broodstock instead.

Was decay of the induced state tested?

Whether the study could distinguish a persistent mark from a transient one. “Not tested” means a single post-conditioning timepoint.

How long the memory was actually given to persist

Days from the end of conditioning to the assessment, log scale, one panel per taxon. Points at 0 d sit in the separated column at left: offspring spawned directly into the challenge, so no persistence was tested. Red marks studies where conditioning made performance worse.
